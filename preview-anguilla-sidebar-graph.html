A Java search engine combining web crawling, text indexing and relevance ranking.

Java · Web scraping · TF-IDF · PageRank

I developed a Java search engine as part of a programming course in my BSc in Mathematical and Technical Software Development. Following the course specification, the application crawls a supplied network of websites and returns ranked results through a command-line interface.

My implementation combines text processing and indexing with a ranking model that brings together textual relevance and the websites’ link structure.
