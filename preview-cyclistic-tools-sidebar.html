Chicago Bike Share Analysis

Capstone project · Google Data Analytics Certificate · 2022

Analyzing historical trip data to inform a marketing strategy to convert casual users to members

Cyclistic is a fictional bike-share company used as the business scenario for this case study. The analysis uses real trip data published by Divvy, Chicago’s bike-share service. I examined differences in usage between casual riders (single-ride and day-pass users) and annual members to inform recommendations for encouraging casual riders to purchase annual memberships.

Project materials

  • Data processing — R Markdown report rendered as HTML, covering data cleaning and preparation.
  • Data analysis — R Markdown report rendered as HTML, examining differences between casual users and members.
  • Presentation (PDF / PowerPoint) — A high-level overview and recommendations for stakeholders.
  • GitHub repository — The complete project.
