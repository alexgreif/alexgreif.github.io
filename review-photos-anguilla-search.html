A Java search engine combining web crawling, text indexing and relevance ranking.

Java · Web scraping · TF-IDF · PageRank

I developed this search engine as a programming course project in my BSc in Mathematical and Technical Software Development. The application crawls websites, scrapes their text content, tokenizes it and builds an index for keyword searches. Search results are ranked by combining textual relevance, based on TF-IDF and cosine similarity, with PageRank scores derived from the websites’ link structure.
